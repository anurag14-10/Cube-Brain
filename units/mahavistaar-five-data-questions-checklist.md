## Unit

According to the MahaVISTAAR pathway contributed by the Department of Agriculture (Government of Maharashtra), EkStep Foundation and OpenAgriNet, the asset is: five questions — Availability, Sovereignty, Accountability, Residency, and Update cadence — to run against every candidate data source before any code is written.

**Purpose:** Turns 'is this data usable' from an intuition into a checklist that can be run against any candidate source consistently.

**Reuse condition:** Domain-general.

## Condition

- **Applies when:** Run against every candidate data source before any code is written (stated as domain-general).
- **Fails when:** Not documented in the source

## Why it is reusable

A five-item checklist any adopter can apply unchanged to any data source.
