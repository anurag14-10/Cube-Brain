## Core question

Which parts can you not build yourselves — and do you have a named partner for each?

## Listening for

Data owners, language models, telephony partners, integrators, field networks. Unnamed dependencies are unmanaged risk.

## Insight form

Dependency map: component × build-or-source × named partner

## Corpus example

Bhili Language Enablement: eight distinct ecosystem roles, all named before model work. Project stalled when the linguist role was unnamed for three months.
