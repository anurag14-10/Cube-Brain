## Core question

Which architecture choices, if wrong, would take six months to undo — and is every data source named, with an accountable owner for each?

## Listening for

Residency, vendor lock-in, sovereignty, orchestration ownership. Not "government data" — ICAR, IMD, APMC, named humans.

## Insight form

Irreversible decisions list + data source registry (source × owner × cadence × accountability)

## Corpus example

Blue Dots: building open, UPI-style shared rails instead of a platform any one organisation owns is named directly as the single most consequential, hardest-to-reverse decision in the pathway.
